# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Svelte 5, TypeScript, and Vite. GitHub Actions builds static assets for GitHub Pages.

## Users

People evaluating Multimedia Downloader and first-time users who want to understand its features and learn the basic workflows before installing it.

## Product Purpose

Explain the Multimedia Downloader project and let visitors explore a browser-only simulation of its application. Success means visitors can understand what the real app does, see the shape of its workflows, and distinguish the simulation from real downloads or conversions.

## Positioning

The real project combines multimedia downloading, format conversion, and optional AI-assisted task planning in a cross-platform application. The website makes those workflows observable and explorable without requiring installation.

## Operating Context

The website is a static GitHub Pages site. Its simulated application runs entirely in the visitor's browser and does not connect to the Python engine, fetch media, convert files, or require credentials.

## Capabilities and Constraints

- The real application supports video and audio downloads, format conversion, batch workflows, and an AI assistant that requires confirmation before running a task queue.
- The website provides an explicitly simulated experience only; all progress, outputs, and activity records are examples generated locally in the browser.
- The first release supports English, Traditional Chinese, and Simplified Chinese, matching the application's existing locales.
- GitHub Actions builds and deploys the static site to GitHub Pages. No application backend is part of this branch.

## Brand Commitments

- The user's Minecraft Auto Fishing repository is a reference for the idea of combining project information with an interactive demonstration. Do not copy its code, text, assets, layout, or visual identity.
- Keep the site's visual design original and use a dark theme.

## Evidence on Hand

- The source project's root README describes the real application's platforms, download and conversion features, AI confirmation flow, supported locales, and web application requirements.
- The source project's existing browser transport simulates operations without downloading or converting files; the preview branch will implement its own isolated simulation.
- No testimonials, customer claims, or performance benchmarks have been provided; do not invent them.

## Product Principles

- Teach through observable workflows as well as concise project information.
- Make the boundary between simulation and real application behavior clear before and during interactions.
- Keep sample URLs, files, output names, progress, and logs clearly fictional.
- Preserve the real product's confirmed terminology and supported languages.
